# WUZZZIK 1.1

**English** | [Русский](#wuzzzik-11-на-русском)

Fixes and new features after 1.0-start. One file: the APK to install (Android 8.0 or newer). Still works offline unless
you turn on the update check.

**New**
- Playlists: create, rename, delete, reorder by dragging, "Add to playlist" from the track menu; playlists appear in
  "Continue listening" and in the backup.
- Favourites and ratings (0.0–10.0 in steps of 0.1) from the track menu; automatic playlists "Favorites" and "Top songs".
- "Share" for a track (track menu) and for a whole album, through the system share sheet.
- Optional update check: asks once, then looks at the latest GitHub release at most once a day and shows a link.
  Nothing is downloaded or installed by the app. This is the only network request and the only reason for the
  internet permission.

**Fixed and changed**
- Top songs on the artist card now work.
- A healthy file is no longer put in quarantine after a crash elsewhere.
- Covers in the queue; shorter swipe distance to open and close the player.
- Portrait orientation only.

**Still not done**
- Search, equalizer, sleep timer, synchronized lyrics, widgets, smart playlists.
- Screens without a mockup (queue, playlists, rating dialog, parts of statistics) may change.

## WUZZZIK 1.1 на русском

Исправления и новые функции после 1.0-start. Один файл: APK для установки (Android 8.0 и новее). По-прежнему
работает офлайн, пока вы не включите проверку обновлений.

**Новое**
- Плейлисты: создание, переименование, удаление, порядок перетаскиванием, «Добавить в плейлист» в меню трека;
  плейлисты есть в «Продолжить прослушивание» и в резервной копии.
- Избранное и оценки (0.0–10.0 с шагом 0.1) из меню трека; автоплейлисты «Избранное» и «Лучшие песни».
- «Поделиться» для трека (меню трека) и для целого альбома через системное окно.
- Необязательная проверка обновлений: спрашивает один раз, затем не чаще раза в сутки смотрит последний релиз на
  GitHub и показывает ссылку. Приложение ничего не скачивает и не устанавливает. Это единственный сетевой запрос и
  единственная причина разрешения на интернет.

**Исправлено и изменено**
- Топ песен в карточке исполнителя работает.
- Исправный файл больше не попадает в карантин после сбоя в другом месте.
- Обложки в очереди; свайп плеера короче.
- Только вертикальная ориентация.

**Ещё не сделано**
- Поиск, эквалайзер, таймер сна, синхронизированные тексты, виджеты, умные плейлисты.
- Экраны без макета (очередь, плейлисты, диалог оценки, части статистики) могут измениться.
