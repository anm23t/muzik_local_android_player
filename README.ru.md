# WUZZZIK

[English](README.md) | **Русский**

Локальный музыкальный плеер для Android, который работает с вашими файлами: читает и редактирует все теги (запись
прямо в файлы), понимает нескольких исполнителей у одного трека и ведёт статистику прослушиваний. Открытый код,
GPLv3, без сервисов Google, по умолчанию работает офлайн. Разработчик: anm23t.

## Возможности

**Библиотека**
- Сканирует аудио на устройстве (MediaStore): песни, альбомы, исполнители, кэш обложек.
- Исключение папок, минимальная длина трека, пересканирование по кнопке.
- Файлы, на которых падает чтение тегов, попадают в карантин и не ломают сканирование.
- Форматы: MP3, FLAC, Ogg/Opus/Vorbis, M4A (AAC и ALAC со встроенным декодером ALAC) и другие, которые умеет Android.

**Воспроизведение**
- Фоновое воспроизведение с уведомлением, экран блокировки и кнопки наушников.
- Очередь: играть следующим, перемешивание, повтор, перетаскивание; очередь и позиция восстанавливаются при запуске.
- Смена трека свайпом по обложке (в плеере и в мини-плеере), свайп вверх по мини-плееру открывает плеер.
- Gapless, crossfade (0-12 с, не между соседними треками одного альбома), ReplayGain (по треку, по альбому, авто,
  предусилитель, защита от клиппинга), пропуск тишины, настройки аудиофокуса и поведения при наушниках.

**Теги**
- Чтение названия, исполнителей, альбома, года, жанров, обложки и текста; правка и запись в файл.
- Безопасная запись: правки идут в рабочую копию, результат проверяется, оригинал сохраняется в резервной копии и
  восстанавливается при любой ошибке.
- Несколько исполнителей на трек: автоматическое разбиение (сначала `;`, иначе `,`), ручная правка, порядок,
  объединение и переименование профилей исполнителей, «запомнить как одного исполнителя» для имён с запятой,
  проверка похожих написаний.
- Пакетная правка альбома: обложка, альбом, исполнители альбома, год, жанры.

**Исполнители и альбомы**
- Карточка исполнителя: альбомы, синглы и «участвует в», фото добавляется долгим нажатием (из сети не загружается).
- Динамический акцентный цвет по обложке играющего трека (можно выключить).

**Статистика**
- События прослушивания со снимком названия и исполнителей, порог засчитывания настраивается, приватный режим
  ставит запись на паузу.
- Топы треков, альбомов и исполнителей (каждый исполнитель считается отдельно) за день, неделю, месяц, год или всё время.
- «Продолжить прослушивание» на главной.

**Данные**
- Резервная копия и восстановление в JSON (статистика, настройки, алиасы, составные имена), автоматическая копия в
  выбранную папку, экспорт истории прослушиваний в CSV.

**Интерфейс**
- Только тёмная тема. Английский и русский языки.

### Чего ещё нет в 1.0

Плейлисты, избранное и оценки в интерфейсе, поиск, эквалайзер, таймер сна, синхронизированные тексты (LRC/TTML),
умные плейлисты, виджеты, Android Auto. Экран очереди, детали экрана статистики и ещё несколько экранов сделаны без
макета и могут измениться. Подробнее в [ROADMAP.md](ROADMAP.md).

## Установка

1. Скачайте файл `.apk` на странице **Releases** этого репозитория.
2. Откройте его на телефоне. Android попросит разрешить установку приложений из этого источника (браузера или
   файлового менеджера), разрешите на время установки.
3. Откройте WUZZZIK и дайте доступ к аудиофайлам.

Нужен Android 8.0 (API 26) или новее.

## Сборка

Требуется: JDK 17+, Android SDK (платформа 35) с NDK `30.0.16248370` и CMake `3.31.6`, компилятор C++ на машине
разработчика для юнит-тестов (Xcode Command Line Tools на macOS, gcc или clang на Linux).

```bash
git submodule update --init --recursive
sdkmanager "ndk;30.0.16248370" "cmake;3.31.6"
./gradlew test assembleDebug
```

Релизная сборка подписывается ключом, описанным в `keystore.properties` в корне проекта (файл не попадает в git:
`storeFile`, `storePassword`, `keyAlias`, `keyPassword`); без этого файла `assembleRelease` выдаёт неподписанный APK.
О работе с кодом см. [CONTRIBUTING.md](CONTRIBUTING.md).
